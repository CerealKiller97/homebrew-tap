# CerealKiller97/homebrew-tap

Homebrew tap for [linkwarden-cli](https://github.com/CerealKiller97/linkwarden-cli), a command-line
client for the [Linkwarden](https://linkwarden.app) bookmark manager.

It works on macOS and Linux, on both Intel/AMD (x86_64) and ARM64.

## Install

```bash
brew install --cask CerealKiller97/tap/linkwarden-cli
```

This adds the tap and installs the cask in one step. Since Homebrew 6.0, items from third-party taps
must be trusted before they're installed. Using the full name `CerealKiller97/tap/linkwarden-cli`
trusts only this cask, so no separate step is needed.

### Installing by the short name

To install with the short name `linkwarden-cli`, add the tap and trust the cask first:

```bash
brew tap CerealKiller97/tap
brew trust --cask CerealKiller97/tap/linkwarden-cli
brew install --cask linkwarden-cli
```

Without `brew trust`, Homebrew 6.0 and later refuses to install from the tap by the short name.
Run `brew trust` with no arguments to list what you've trusted. Homebrew recommends trusting single
casks rather than whole taps; see [Tap Trust](https://docs.brew.sh/Tap-Trust).

Check that it works:

```bash
linkwarden --version
```

Then sign in to your Linkwarden instance:

```bash
linkwarden init
```

## Upgrade

```bash
brew update
brew upgrade --cask linkwarden-cli
```

## Uninstall

```bash
brew uninstall --cask linkwarden-cli
brew untrust --cask CerealKiller97/tap/linkwarden-cli
brew untap CerealKiller97/tap
```

## Shell completions

The cask installs completions for bash, zsh and fish. They load once your shell is set up for
Homebrew's completions. See Homebrew's
[shell completion guide](https://docs.brew.sh/Shell-Completion) if `linkwarden <Tab>` does nothing.

## macOS: "cannot be opened because the developer cannot be verified"

The `linkwarden` binary isn't signed or notarized by Apple. The cask removes the quarantine flag
after installing, so macOS shouldn't block it. If macOS still blocks it, clear the flag yourself:

```bash
xattr -dr com.apple.quarantine "$(brew --caskroom)/linkwarden-cli"
```

## How this tap is updated

`Casks/linkwarden-cli.rb` is generated by [GoReleaser](https://goreleaser.com) for each
linkwarden-cli release, which opens a pull request here. Don't edit it by hand: changes are
overwritten by the next release. Report problems in the
[linkwarden-cli issues](https://github.com/CerealKiller97/linkwarden-cli/issues).
